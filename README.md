# discollection-viewer

> **This project is archived.** Further development has moved to [`discollection-web`](https://github.com/dainguyendo/discollection/tree/main/discollection-web) within the [discollection](https://github.com/dainguyendo/discollection) monorepo.

This was a viewer for the output of the `organize` command from the [discollection CLI project](https://github.com/dainguyendo/discollection). The output of the `organize` command is a JSON file that contains your organized Discogs library collection. You could take that JSON file and upload it to this viewer to see your collection in its organized state.
